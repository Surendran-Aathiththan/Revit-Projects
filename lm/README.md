# lm: Lumion Export of the Planning Model

COLLADA (`.dae`) export of the Revit planning model from [Uni Project 1 (CE2130)](../Uni%20Project%201%20CE2130), prepared for rendering in **Lumion**.

| File | Description |
|---|---|
| `Planning.dae` | Model geometry exported from Revit (≈ 38 MB) |
| `Planning_Textures/` | Material textures referenced by the `.dae` file; keep them next to it |

Import `Planning.dae` into Lumion (or another tool that reads COLLADA, such as Blender) with the textures folder alongside it.
