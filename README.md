# Revit Projects

Building information models (BIM) and planning drawings produced in **Autodesk Revit**, with drafting in **AutoCAD** and rendering exports for **Lumion**. Most of this work comes from the University of Peradeniya module **CE2130**.

![Floor plan](revit%2001/323.png)

## Projects

| Project | Description | Deliverables |
|---|---|---|
| [Uni Project 1 – CE2130](Uni%20Project%201%20CE2130) | Two-storey building design | Ground and first floor plans, front and side elevations, sections X-X and Y-Y, roof arrangement, foundation & column layout, septic tank, door and window schedule, Lumion render export |
| [Uni Project 2 – CE2130](Uni%20Project%202%20CE2130) | Two-storey building design | Ground and first floor plans, front and side elevations, sections X-X and Y-Y, roof plan |
| [Uni Project 3 – CE2130](Uni%20project%203%20CE2130) | Two-storey building design | Ground and first floor plans, front and side elevations, sections X-X and Y-Y, roof plan |
| [revit 01](revit%2001) | Architectural model | Floor plan and model |
| [sTRUCTURE](sTRUCTURE) | Structural model | Revit structural model |

## Skills demonstrated

- Architectural modelling: walls, floors, roofs, doors and windows
- Producing plans, elevations and sections from a single model
- Foundation and column layouts
- Exporting to AutoCAD (DWG/DXF) and to Lumion (DAE) for rendering

## Opening the files

The drawing PDFs can be viewed directly on GitHub. Open the `.rvt` models in **Revit 2022 or later**.
